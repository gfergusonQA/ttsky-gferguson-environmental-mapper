## How it works

The **Environmental Mapping Processor** is a small digital ASIC designed for low-power environmental monitoring and mobile geospatial data-collection applications.

<img width="382" height="606" alt="Screenshot 2026-08-21 at 2 32 38 PM" src="https://github.com/user-attachments/assets/981ddc5d-5598-4ffd-b4b8-3688762c85e1" />

The ASIC combines two processing functions:

- **Environmental processing** — statistics, programmable thresholds, and anomaly detection for temperature, humidity, and atmospheric pressure.
- **Spatial processing** — compact X/Y position processing for determining distance from a programmed target area and identifying location-aware environmental events.

The intended portable system combines the ASIC with an environmental sensor, GNSS receiver, low-power interface controller, display, storage, and rechargeable battery.

### Environmental processing

Environmental measurements are supplied as unsigned 8-bit values.

The ASIC maintains independent state for:

- Temperature
- Relative humidity
- Atmospheric pressure

For each environmental channel, the ASIC can maintain:

- Latest measurement
- Minimum measurement
- Maximum measurement
- Eight-sample average
- Programmable low threshold
- Programmable high threshold
- High/low anomaly detection

The eight-sample average is implemented using an accumulator followed by a three-bit right shift (`sum >> 3`). This avoids the area cost of a general-purpose hardware divider.

The three environmental channels operate independently, allowing measurements from one sensor type to be processed without overwriting statistics for the others.

### Spatial processing

The final design adds a compact spatial-processing engine intended for mobile environmental mapping.

Rather than processing full GNSS latitude and longitude values directly, the ASIC receives a compact local X/Y coordinate generated by the external interface controller.

The spatial engine stores:

- Current X/Y position
- Target X/Y position
- Programmable target radius

It calculates Manhattan distance in hardware:

    distance = |current_x - target_x| +
               |current_y - target_y|

The ASIC then determines whether the current position is inside the programmed target zone.

This result can be combined with environmental anomaly detection to produce a **location-aware environmental event**.

For example:

    Temperature = above programmed threshold
    Current position = inside target zone

                    ↓

         LOCATION-AWARE EVENT

This allows the ASIC to perform dedicated environmental and spatial decision-making without requiring a general-purpose processor to perform those calculations.

## Intended mobile device

The Tiny Tapeout ASIC is intended to become the processing core of a small, battery-powered environmental mapping device.

A complete portable system could use:

- **u-blox SAM-M10Q GNSS module** — provides live geographic position and includes an integrated GNSS antenna.
- **BME280 environmental sensor** — measures temperature, relative humidity, and atmospheric pressure.
- **Ultra-low-power interface microcontroller** — communicates with the GNSS and sensor, converts GNSS coordinates into the ASIC's compact X/Y representation, supplies data to the ASIC, reads ASIC results, drives the display, and handles storage.
- **Small Memory LCD** — displays current measurements, GNSS status, position, spatial-zone status, and environmental alerts.
- **MicroSD card and socket** — records position, environmental measurements, timestamps, and ASIC results for later GIS analysis.
- **Rechargeable single-cell LiPo battery**.
- **LiPo charging/protection circuitry**.
- **Low-quiescent-current voltage regulation**.
- **Momentary power button and low-power soft-power circuitry**.
- **Tiny Tapeout ASIC and supporting PCB**.

The interface controller handles communication and data movement rather than duplicating the ASIC's environmental and spatial algorithms.

The BME280 is not a fundamental requirement of the architecture. Other digital environmental sensors could be substituted later as long as their measurements are converted into the digital representation expected by the ASIC.

A custom PCB containing these components could form a compact handheld instrument approximately in the size class of a small mobile phone or handheld GPS receiver. Prototype versions using breakout boards would be larger.

## Low-power mobile operation

The intended device uses a button-controlled power architecture.

While the device is not being used, most of the system can remain powered down or in a low-power state.

Pressing the power button wakes the system and enables:

1. Continuous GNSS tracking while the device is being carried.
2. Periodic environmental measurements.
3. Environmental and spatial processing by the ASIC.
4. Display updates.
5. Optional logging to microSD.

When the device is turned off, the GNSS, sensor, display, and processing circuitry can return to low-power states.

This architecture is intended to minimize average power consumption while still allowing continuous location tracking during active field use.

## How to test

Set `ena` high and reset the ASIC by driving `rst_n` low for at least two clock cycles, then return `rst_n` high.

### Environmental measurements

Select an environmental channel and present the unsigned 8-bit measurement on `uio_in[7:0]`.

Assert `sample_valid` for one rising edge of `clk`.

The ASIC updates the statistics and anomaly state for that environmental channel.

For example, eight temperature samples:

    64, 66, 68, 70, 72, 74, 76, 78

produce:

    Latest  = 78
    Minimum = 64
    Maximum = 78
    Average = 71

### Programmable thresholds

Example:

    Temperature LOW  = 50
    Temperature HIGH = 100

    Temperature = 75
        → no anomaly

    Temperature = 110
        → TEMP_HIGH = 1
        → ANY_ANOMALY = 1

    Temperature = 40
        → TEMP_LOW = 1
        → ANY_ANOMALY = 1

### Spatial processing

A current X/Y coordinate, target X/Y coordinate, and target radius can be programmed into the spatial engine.

For example:

    Current = (7, 9)
    Target  = (4, 7)
    Radius  = 6

The ASIC calculates:

    |7 - 4| + |9 - 7|
       3    +    2
            = 5

Since:

    5 <= 6

the current position is classified as inside the target zone.

If an environmental anomaly is simultaneously present, the ASIC can assert a location-aware environmental event.

## External sensor interface

The ASIC operates on digital measurements rather than directly sensing analog environmental conditions.

For the intended portable implementation, a low-power interface controller communicates with the BME280 (or another compatible environmental sensor) and GNSS receiver and presents compact digital measurements and coordinates to the ASIC.

This keeps protocol parsing, GNSS message handling, display control, and storage outside the limited Tiny Tapeout tile while reserving the custom silicon for dedicated environmental and spatial computation.
